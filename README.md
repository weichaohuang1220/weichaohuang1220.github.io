# Workflow explorations

A static collection of illustrative video-processing, language-model-training, and agent-workflow demonstrations.

## Editing

- `dist/index.html`: demonstration content.
- `dist/styles.css`: layout and animation styles.
- `dist/script.js`: navigation, step selection, and playback.

Serve `dist/` with a local HTTP server for previews. GitHub Actions publishes `dist/` when `main` changes. No build step is required.

The three demonstrations contain 14 independent scenes with authored examples, not recorded runs. They expand inline and support manual step selection and pausable playback. Reduced-motion preferences are respected.
